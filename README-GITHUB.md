# BankManager — GitHub Build

## ساخت APK
1. محتویات این پروژه را داخل یک GitHub Repository قرار دهید.
2. به تب **Actions** بروید.
3. Workflow با نام **Build Android APK** را انتخاب کنید.
4. روی **Run workflow** بزنید.
5. پس از پایان Build، در بخش **Artifacts** فایل `BankManager-debug-apk` را دانلود کنید.
6. APK داخل آن فایل را روی گوشی اندرویدی نصب کنید.

این Workflow از JDK 17 و Gradle استفاده می‌کند و APK نسخه Debug می‌سازد.
