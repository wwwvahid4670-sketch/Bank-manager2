# BankManager Android
پروژه آماده برای ساخت APK برنامه مدیریت حساب‌ها و کارت‌های بانکی.

ویژگی‌ها: رابط فارسی و راست‌چین، ثبت حساب و کارت، حذف اطلاعات، نگهداری محلی، و امکان باز کردن اپ بانک با Package Name.

برای ساخت APK در محیط آنلاین سازگار با Android/Gradle، پروژه را آپلود و task `assembleDebug` را اجرا کنید.

خروجی: `app/build/outputs/apk/debug/app-debug.apk`

نکته امنیتی: رمز کارت، PIN و رمز اینترنت‌بانک را در این برنامه ذخیره نکنید.
